Creates one fencing device for each saved iDRAC definition. Names come from step 08a and are not renamed here. Resources with matching definitions are verified and reused; conflicting resources stop the operation without being overwritten.

Creation is issued once from one cluster coordinator. Before applying changes, ClusterWeaver verifies all nodes, quorum, cluster identity, fence agents and iDRAC status from surviving peer nodes. Commands are staged in a protected CIB file and pushed together. No power-off or reboot test is requested.
